# Maktabah Maftoohah — Sunan ad-Darimi (سنن الدارمي)

> Part of the **Maktabah Maftoohah** (المكتبة المفتوحة) Open Islamic Heritage Library.

## Features
* **Zero-Build Vanilla ES6**: Runs natively in any browser with zero build tools or bundlers.
* **Offline First & PWA**: Accessible without an active internet connection.
* **Authentic Primary Sourcing**: Strictly preserved authentic text, isnad, and takhrij.

## Development & Testing
```bash
python scripts/serve.py --port 8000
python scripts/verify_project.py
python scripts/verify_data_integrity.py
```
